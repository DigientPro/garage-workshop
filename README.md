# Мастерская · 3D-план

Статический просмотрщик гаража с упрощённой моделью из ВМК. В модели показаны настил, лаги, эскиз люка со стороны ворот, два обогревателя и шесть светильников с трассами проводки. Модель отсчитывается от локальной системы координат.

## GitHub Pages

В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, затем **main** и **/docs**. Нажмите **Save**. Сборка для публикации уже находится в `docs/`.

## Локально

Из корня репозитория запустите `python3 -m http.server 8080 --directory docs` и откройте `http://localhost:8080`. Чтобы обновить браузерную сборку после правок в `src/viewer.js`, выполните `npm ci` и `npm run build`.
